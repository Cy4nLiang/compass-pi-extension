# 示例数据说明

`demo-market.csv` 用于快速体验导入与粗筛流程。文件中所有 ASIN（`B0DEMO` 前缀）、品牌、标题、价格、评分、评论数、销量与搜索量均为**虚构演示数据**，与任何真实 Amazon listing、品牌或卖家无关。运营使用手册中出现的成本参数示例同理，均为教学用虚构数字。

`agents/` 下三份是 `compass_dispatch` 子代理定义的**示例**：把它们复制到宿主项目的 `.pi/agents/<同名>.md` 就会覆盖内置模板。三点要记住：正文**整段替换** systemPrompt，所以枚举与硬约束必须自己写全（漏一个值子代理会天天判失败）；frontmatter 只认 `model` / `max_tokens` / `timeout_ms`，出现 `tools` 会被直接拒绝；正文会**逐字发往所配置的模型供应商**，所以只写通用措辞，内部口径留在自己工作区、由主会话在结果下方本地拼接。
